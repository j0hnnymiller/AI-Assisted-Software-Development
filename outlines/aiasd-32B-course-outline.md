# AI-Assisted Brownfield Development — Course Outline (AIASD-32B)

## Overview

A two-day intensive course focused on AI-assisted brownfield software development, legacy code modernization, and technical debt management. This course teaches developers how to use AI tools effectively when working with existing codebases.
